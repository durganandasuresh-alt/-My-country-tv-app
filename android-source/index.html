My Country TV Android Studio Project

Android App Documentation

Welcome to the native Android Studio project for My Country TV. This application is pre-configured to build a native Android TV and Mobile APK.

🚀 How to Compile into APK in Android Studio:

  1. Open Android Studio.
  2. Click Open and choose this extracted project directory.
  3. Allow Gradle to sync automatically.
  4. In the top menu, click: 
    Build → Build Bundle(s) / APK(s) → Build APK(s)
  5. Your ready-to-install APK will be saved at: 
    app/build/outputs/apk/debug/app-debug.apk
  6. Copy app-debug.apk to your Android Phone or Android TV box and install!

📱 Features:

  • HLS Live Video Acceleration: Full hardware decoder support for .m3u8 streaming feeds.
  • Android TV Remote: Full D-Pad navigation, Enter, and Back button handling.
  • Server Configurator: Remembers your PC local IP address and auto-reconnects on launch.
  • Offline Error Recovery: Clean reconnect screen with 1-tap retry.

⚙️ Default Connection Settings:

Default server URL is configured to: http://192.168.1.7:5000

You can change the IP anytime directly in the app's settings dialog or edit MainActivity.java (DEFAULT_SERVER_URL).
